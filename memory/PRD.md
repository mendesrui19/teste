# SQZ — squiiz by Lemon Jelly (PRD)

## Original Problem Statement
> "tens no github todas as fotos dos meus produtos logos etc, preciso que cries um site para a minha loja. site colorido divertido letras grandes pelo menos na par tem de ter aquilo da parte do 'squiiz by Lemon jelly'. Slogan no site. Em alguma parte a dizer squizz. Produtos só da vendas dos produtos. Videos de limões a espremer e gotas de limões para ser um site animado. quero o site com video animado. sobre nos dentro da pagina de inicio e depois a pagina de produtos."

## User Choices (literal)
- Brand: **SQZ**
- Slogan: **"When life gives you lemon..."**
- "squiiz by Lemon Jelly" referenced visibly across the site
- Catalog only (no checkout)
- Animated video generated by us (lemon being squeezed + drops)
- Pages: Início (with About Us inline + featured products) and Produtos
- Language: Portuguese

## Architecture
- **Frontend**: React 18 + React Router + Tailwind CSS + Framer Motion (Fredoka + Libre Franklin via Google Fonts)
- **Backend**: FastAPI (single `/api/health` endpoint — site is purely static catalog)
- **Data**: Products are static in `/app/frontend/src/data/products.js` (36 products, 5 categories)
- **Assets**: Brand images cloned from `mendesrui19/teste` GitHub → `/app/frontend/public/assets/{logo,colares,brincos,aneis,capas,acessorios,bijutaria,paleta}/`

## Design System
- Pop / Neo-Brutalism aesthetic (thick black borders, hard shadows, rounded blocks)
- Colors: Yellow #FBD503, Blue #04A5E6, Pink #FC6CA7, Green #B2D801, Lavender #D0B2FF, Orange #FE8E04, Ink #151515
- Big display fonts (Fredoka)
- SVG lemon squeeze animation + falling colored drop particles + scrolling marquees
